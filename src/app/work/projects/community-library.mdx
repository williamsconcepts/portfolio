## Overview

A simple frontend-based library management system built with HTML, CSS, and JavaScript. This project demonstrates Object-Oriented Programming (OOP), DOM manipulation, event handling, and browser localStorage persistence.

The application allows users to manage books and members, borrow and return books, and view library statistics directly from the browser.

## Features

### Book Management

- Add new books
- Store book title, author, ISBN, and year published
- Track availability status
- View available and borrowed books

### Member Management

- Register new library members
- Store member name and member ID
- Display registered members

### Borrow & Return System

- Borrow available books
- Return borrowed books
- Automatically update availability status

### Local Storage Persistence

- Save books and members in browser storage
- Keep data after refreshing the page
- Reload stored library data automatically

### Library Dashboard

Displays:

- Total books
- Available books
- Borrowed books
- Registered members

## Technologies Used

- HTML5
- CSS3
- JavaScript ES6+

JavaScript concepts implemented:

- Classes
- Constructors
- Private fields
- Getters and setters
- Static properties
- Array methods such as map(), filter(), find(), findIndex(), and splice()
- DOM manipulation
- Event listeners
- Local Storage API

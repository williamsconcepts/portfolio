## Overview

Maintx360 is a web-based Computerized Maintenance Management System (CMMS) designed to help oil and gas companies manage equipment maintenance activities, work orders, technicians, and maintenance records from a centralized digital platform. The system is built to reduce downtime, improve planning, and increase visibility into asset performance and maintenance operations.

## Problem Statement

Many maintenance teams still rely on paper logs, spreadsheets, email chains, and WhatsApp coordination. These methods often lead to missed maintenance activities, equipment breakdowns, untracked work orders, poor documentation, increased operational costs, and reduced asset reliability. Maintx360 digitizes these operations to improve efficiency, accountability, and uptime.

## Project Objectives

The primary goals of Maintx360 are to:

- Digitize maintenance operations
- Centralize asset information
- Improve preventive maintenance planning
- Track work orders efficiently
- Manage technicians and assignments
- Maintain historical maintenance records
- Provide dashboards and operational insights

## Target Users

- **Maintenance Manager**: Monitors activities, approves work orders, and reviews reports
- **Maintenance Technician**: Executes tasks, updates work order status, and records activities
- **Operations Supervisor**: Monitors asset condition and operational risks
- **Administrator**: Manages users, configurations, and master data

## Key Features

### Dashboard

Provides an overview of maintenance operations with KPIs such as:

- Total assets
- Active work orders
- Completed work orders
- Upcoming maintenance
- Maintenance completion rate
- Available technicians

### Asset Management

Allows teams to maintain a complete asset register with details such as:

- Asset ID
- Asset name
- Asset type
- Location
- Status
- Installation date
- Manufacturer
- Serial number

### Preventive Maintenance

Helps teams plan maintenance before failures occur by scheduling:

- Asset maintenance type
- Frequency
- Start date
- Next due date
- Assigned technician

### Work Order Management

Tracks maintenance requests from creation to completion with:

- Work order number
- Asset reference
- Priority levels
- Assigned technician
- Status updates
- Due date monitoring

### Technician Management

Supports the management of maintenance personnel, including:

- Employee ID
- Full name
- Department
- Skill set
- Phone number
- Email address

## Technologies Used

- **Frontend**: HTML5, CSS3, and Vanilla JavaScript
- **Storage**: Browser LocalStorage
- **Charts & Analytics**: Chart.js
- **Future Backend**: Node.js, Express.js, and MongoDB

## MVP Scope

The initial version focuses on three core modules:

- **Asset Register**: Add, edit, delete, and search assets
- **Work Orders**: Create, assign, update, and view work orders
- **Technician Management**: Add, edit, and assign technicians to work orders

## Future Enhancements

Planned improvements include:

- User authentication and role-based access control
- QR code asset identification
- Email notifications
- Maintenance approval workflow
- Mobile app integration
- IoT sensor integration
- Predictive maintenance analytics
- Cloud deployment

## Business Value

Maintx360 helps organizations improve equipment reliability, reduce downtime, increase technician productivity, strengthen compliance, and support digital transformation initiatives.

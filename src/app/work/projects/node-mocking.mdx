## Overview

A real-time mock product service built with **Node.js, Fastify, REST APIs, WebSockets, and a custom Command-Line Interface (CLI)**. The application demonstrates how multiple clients can interact with the same backend using different communication methods.

The frontend retrieves product data through REST endpoints while maintaining a persistent WebSocket connection for live order updates. A separate Node.js CLI application simulates incoming product orders by sending HTTP requests directly to the backend, allowing connected clients to receive updates instantly without refreshing the page.

The project showcases modern backend development concepts, including API design, event-driven programming, WebSocket communication, and building reusable developer tools.

## Features

### Product API

- Retrieve products by category
- Create new products through REST endpoints

- Custom Node.js CLI

- Trigger live updates across connected clients

- Simulated product inventory

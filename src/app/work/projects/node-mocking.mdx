## Overview

A real-time mock service built with **Node.js, Fastify, and WebSockets**. The project combines traditional REST APIs with persistent WebSocket connections to simulate a product service that streams live order updates to connected clients.

Rather than repeatedly polling the server for changes, the frontend establishes a long-lived WebSocket connection, allowing the server to push updated order counts instantly whenever new orders are received. This project demonstrates how REST APIs and WebSockets can work together to create responsive, real-time applications.

## Features

### Product API

- Retrieve products by category
- Add new products through REST endpoints

### Real-Time Updates

- Live product order count updates
- Persistent WebSocket connections
- Server-to-client event broadcasting
- Dynamic category subscription
- Instant UI updates without page refreshes

### Mock Service

- Mock order generation

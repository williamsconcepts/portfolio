## Overview

PetroFlow is a full-stack enterprise web application inspired by modern oilfield production management systems. The platform enables field operators and production engineers to monitor well performance, capture production data, track equipment downtime, manage emissions, and generate regulatory reports through a centralized dashboard.

It is designed as a production intelligence platform for upstream operations, combining operational visibility, analytics, and role-based access in one experience.

## What the Platform Does

PetroFlow helps teams manage the core operational workflows of an oil and gas business, including:

- Monitoring oil, gas, well, downtime, and emissions KPIs
- Tracking production trends and monthly performance
- Managing well records and production data
- Handling equipment maintenance and reliability insights
- Capturing and reviewing downtime events
- Recording emissions data for reporting and compliance
- Generating reports with export-ready workflows

## Core Features

- Enterprise-style dashboard with production and operational KPIs
- Production trend, monthly production, downtime, and emissions charts
- Well CRUD, search, status filtering, and detail pages
- Production record CRUD with daily, monthly, and trend views
- Equipment CRUD with maintenance tracking and reliability insights
- Downtime event create, update, and close workflow
- Emissions capture and monitoring with reporting support
- Reports module with PDF and Excel-style export actions
- Admin user and role management screens
- Settings for thresholds, notifications, security, and retention
- AI-inspired insights, predictive maintenance cards, and activity logs
- Loading, empty, and error states
- Light and dark mode support

## Tech Stack

- Next.js 15 App Router
- TypeScript
- Tailwind CSS
- Reusable UI components
- PostgreSQL
- Prisma ORM
- Auth.js / NextAuth credentials authentication
- Role-based authorization
- Recharts
- React Hook Form
- Zod validation


## Project Highlights

PetroFlow demonstrates full-stack engineering, data visualization, enterprise software architecture, operational analytics, role-based access, and environmental monitoring in an oil and gas context suitable for a capstone presentation.

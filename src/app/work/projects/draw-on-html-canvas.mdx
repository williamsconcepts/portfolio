Visit the live demo: [Draw-On-It](https://draw-on-html-canvas.netlify.app/)

## Overview

Draw-On-It is a creative drawing application built with HTML5 Canvas. It offers a full-screen drawing surface where users can sketch freely with dynamic, hue-based colors that cycle smoothly across the color spectrum.

The experience is designed to feel expressive and interactive, with smooth strokes, responsive behavior, and automatic saving so artwork persists across refreshes.

## Features

- Full-screen canvas drawing surface
- Dynamic hue-based color transitions while drawing
- Smooth rounded strokes for a more natural look
- Responsive layout that adapts to the browser window
- Automatic local storage persistence for saved drawings
- Clear canvas button to reset the artwork instantly

## How It Works

Users can click and drag across the canvas to draw. Each stroke uses an HSL color value that changes progressively, creating a vibrant rainbow effect. The drawing is automatically stored in the browser and restored when the page reloads.

## Technologies Used

- HTML5 Canvas
- CSS3
- JavaScript
- Local Storage API

## Overview

A RESTful Blog API built with **Express.js, Knex.js, and SQLite**. The application provides a complete backend for managing blog posts, categories, comments, and likes through RESTful endpoints.

It demonstrates backend development concepts such as routing, CRUD operations, relational database management, migrations, query building, and API design using Express.js and Knex.js.

## Features

### Posts

- Create new blog posts
- View all posts with their comments
- View a single post
- Update existing posts
- Delete posts with fewer than 5 comments
- Like posts

### Categories

- Create categories
- View all categories
- Assign categories to posts
- Delete categories that have no posts assigned

### Comments

- Add comments to posts
- Associate comments with individual posts
- View comments by post

### Popular Posts

Rank blog posts based on:

- Number of likes

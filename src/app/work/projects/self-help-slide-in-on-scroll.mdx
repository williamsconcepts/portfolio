## Overview

Self-Help Slide on Scroll is a lightweight frontend web application designed to deliver daily inspiration through beautiful, scroll-triggered animations. As visitors move down the page, motivational quote images gracefully slide in from alternating sides, creating an engaging and immersive reading experience.

The project showcases modern frontend development techniques including dynamic DOM generation, event handling, lazy loading, responsive layouts, and smooth CSS animations—all without relying on external libraries or frameworks.

## Features

### Scroll-Based Animations

- Images slide into view as users scroll
- Alternating left and right entrance animations
- Smooth fade and transform transitions
- Responsive animation behavior

### Dynamic Image Gallery

- Automatically generates 100 motivational quote images
- Eliminates repetitive HTML markup
- Easily scalable to hundreds of images

### Performance Optimization

- Lazy loading for faster page loads

- Smooth scrolling experience

### Responsive Design

- Mobile-friendly layout

### User Experience

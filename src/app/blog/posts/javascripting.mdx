Learning to code isn’t just about reading syntax — it’s about *doing*.  
That’s why I created **JAVASCRIPTING: A Hands-On Guide to Learning JavaScript**, a workbook that takes you step by step through the essentials of programming with JavaScript.

## What’s Inside

This book covers **20 core exercises**, each focusing on a fundamental concept:

- Variables and strings  
- Arrays and objects  
- Functions and arguments  
- Conditionals and loops  
- Scope and state management  

Each chapter includes clear explanations, runnable examples, and a challenge to reinforce learning. By the end, you’ll not only understand the basics but also gain the confidence to write your own programs.

## Why This Book?

Unlike traditional tutorials, this guide is **exercise-driven**. You’ll type out code, run it, break it, and fix it — building real programming instincts along the way.  

It’s perfect for:  
- Beginners starting their coding journey  
- Students looking for structured practice  
- Self-taught developers who want a solid foundation
